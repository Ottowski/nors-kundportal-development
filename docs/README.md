# Dokumentation – Kundserviceportalen (NORS)

Här samlar teamet all dokumentation för projektet. Varje ämne har en egen fil
så att vi kan skriva samtidigt utan att krocka.

## Innehåll

| Fil                                        | Innehåll                                    | Ansvarig           |
| ------------------------------------------ | ------------------------------------------- | ------------------ |
| [projekt.md](projekt.md)                   | Avgränsning, teknikval och arbetsfördelning | Alla               |
| [beslut.md](beslut.md)                     | Beslutslogg: datum, beslut, motivering, vem | Alla               |
| [oppna-fragor.md](oppna-fragor.md)         | Frågor som inte är bestämda än              | Alla               |
| [ai-arbetssatt.md](ai-arbetssatt.md)       | Hur teamet arbetar med AI                   | Alla               |
| [verifieringsplan.md](verifieringsplan.md) | Tester: vad, varför, hur de körs, resultat  | Alla               |
| [veckostatus.md](veckostatus.md)           | Veckostatus vecka 5–8                       | Alla               |
| [specs/](specs/)                           | En specifikation per del                    | Den som äger delen |
| [redovisningar/](redovisningar/)           | Individuella redovisningar                  | Var och en         |

## Så här skriver vi

- Ändra i den fil som gäller ditt ämne.
- Specar och redovisningar: bara ägaren ändrar i sin egen fil.
- Hämta senaste (`git pull`) innan du börjar skriva.
