# Beslutslogg

Här står projektövergripande beslut: teknik, lagring, struktur och arbetssätt. Beslut som bara gäller en spec skrivs i den specen, se [spec-driven-dev.md](specs/spec-driven-dev.md). Veckostatus beskriver vad som gjorts och länkar hit.

Lägg nya beslut sist.
