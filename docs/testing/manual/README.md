# Manual checks

The manual checks, their steps and every recorded run are in the
[verification plan](../../verifieringsplan.md#manuella-kontroller):

- [Hela kedjan mot riktig backend](../../verifieringsplan.md#hela-kedjan-mot-riktig-backend)
- [K1 – bara tangentbord](../../verifieringsplan.md#k1--bara-tangentbord)

This folder holds only attachments for a recorded run, such as screenshots. Name them
`YYYY-MM-DD-<check>-step<n>.png`, for example `2026-11-12-full-chain-step5.png`, and link them from
the run's row in the verification plan. Use made-up data only.
